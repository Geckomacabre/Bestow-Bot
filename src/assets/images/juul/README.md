# /juul icons

Put these PNGs here:

- `juul.png` — the juul icon shown in `/juul` replies (uploaded as-is). **This one is enough on its own.**
- `battery.png` — optional. A **full** battery; the empty-to-full levels are cut from it automatically
  (the green fill is emptied from the top, turning amber at two bars and red at one)

The bot uploads them as its own emojis on start. Without `juul.png` it uses 🖊️; without `battery.png` the battery shows 🟩🟨🟥.
