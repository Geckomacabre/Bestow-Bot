# /juul icons

Put two PNGs here:

- `juul.png` — the juul icon shown in `/juul` replies (uploaded as-is)
- `battery.png` — a **full** battery; the empty-to-full levels are cut from it automatically
  (the green fill is emptied from the top, turning amber at two bars and red at one)

The bot uploads them as its own emojis on start. Until both files are here it uses 🖊️ and 🟩🟨🟥.
