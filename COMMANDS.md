## ⚙️ Config

### /config

Server configuration

- `/config counting` — Configure the counting channel
- `/config streaming set [channel] [role] [message]` — Configure streaming settings
- `/config streaming view` — View current streaming settings
- `/config starboard channel <channel>` — Set the starboard channel
- `/config starboard threshold <count>` — Set minimum reaction count
- `/config starboard emoji <emoji>` — Set the reaction emoji to watch
- `/config starboard toggle` — Enable or disable the starboard
- `/config starboard view` — View current starboard settings
- `/config topics setup <channel> <interval> [mode]` — Set up topic rotation for a channel
- `/config topics remove <channel>` — Stop topic rotation for a channel
- `/config topics add <channel> <topic>` — Add a topic to a channel's rotation
- `/config topics delete <id>` — Remove a topic by ID
- `/config topics list <channel>` — List topics for a channel
- `/config topics post <channel>` — Manually post the next topic now
- `/config timezone set <timezone>` — Set your timezone
- `/config timezone remove` — Unset your timezone
- `/config timezone view [highlight]` — View all timezones in this server
- `/config freegames setup <channel> [ping]` — Set up the free game tracker
- `/config freegames platforms [epic] [steam] [gog]` — Choose which platforms to track
- `/config freegames ping [role]` — Set or clear the ping role
- `/config freegames disable` — Disable the free game tracker
- `/config freegames view` — View tracker settings
- `/config freegames check` — Check for free games now and post any new ones
- `/config serverstats view [hours]` — View server activity stats
- `/config serverstats add <type> [label]` — Create an auto-updating stat channel
- `/config serverstats remove <id>` — Remove a stat channel
- `/config serverstats list` — List all stat channels
